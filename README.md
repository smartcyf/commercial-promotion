# Beyond These Stars Production Calculator & Settlement Planner (Kewa Toolkit)

🔗 **Live Interactive Web App:** [https://beyond-these-stars-calculator.smartcyf.workers.dev/](https://beyond-these-stars-calculator.smartcyf.workers.dev/)

A free, zero-login interactive calculator and layout planner for **Beyond These Stars** (developed by Balancing Monkey Games, published by Hooded Horse). Built with verified data from the official wiki for the October 2026 release.

## Key Features

- **Settlement Bill of Materials (BOM) & Chain Calculator:** Select from all 64 buildings to calculate total raw construction materials (`Wood`, `Stone`, `Iron`, `Tool`, `Plank`, `Steel`, `Glass`, `Cement`, `Electronics`, `Laser`), required Peep workers, Hut equivalents, Power grid load, and Storage Shed counts.
- **Interactive Building Adjacency Bonus & Penalty Simulator:** Check exact neighbor rules before placing footprints on Kewa's back:
  - **Hut:** `+20% Happiness` next to 2× Potato Patches (`+40%` with early Perk); `-20% Water Pump speed` if touching a Water Pump.
  - **Woodcutter:** `+30% Storage` when surrounded by 5× Forest tiles; `-20% Production Speed` when touching another Woodcutter.
  - **Ore Smelter:** `+20% Production Speed` next to 1× Cleaner; `-30% Storage & -1 Workplace` when touching another Ore Smelter.
  - **Water Pump:** `+30% Storage` on river outcroppings surrounded by 3× underwater tiles.
- **By-Product Bottleneck & Soft-Lock Solver:** Prevent production halts from full output buffers (`Wood Waste`, `Soot`, `Slag`, `Sludge`, `Goo`) and calculate `Storage Shed` (80/tile) vs. `Warehouse` (120/tile) capacity.
- **Peep Food & Beverage Happiness Tier List:** Full recovery database (`Hot Casserole +200`, `Cold Snack +150`, `Hot Matcha Latte +150`, `0.75` vs `0.55` Exhaustion recovery).
